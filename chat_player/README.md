# Fake Chat Player - ZLCube Theme

Página local para simular conversaciones en tiempo real con temas:
ZLCube / GitHub Pages, Instagram, WhatsApp, Telegram, Teams y X/Twitter.

## Uso
1. Abre `index.html` en tu navegador.
2. Elige el tema `ZLCube / GitHub Pages`.
3. Edita nombres, avatars y mensajes JSON.
4. Dale Play.
5. Activa `Chroma key` si lo vas a insertar sobre un video.
6. Usa `Ocultar controles` para grabar solo el chat.

## Assets
El tema ZLCube usa:
- `assets/avatar.png`
- `assets/bg.png`
- `assets/posts/` como material visual extra por si quieres reutilizarlo.
