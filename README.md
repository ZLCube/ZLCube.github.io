# 🐉 ZLCube GitHub Pages Blog

Cyberpunk / anime styled personal blog.

## 🚀 Deploy

Push directly to:

```bash
zlcube.github.io
```

Then enable GitHub Pages in:

Settings → Pages → Deploy from branch → main

## 📁 Structure

- index.html
- style.css
- script.js
- assets/

## ✨ Features

- Matrix aesthetic
- Glassmorphism
- Anime cyberpunk style
- Responsive layout
- Floating avatar
- Interactive cards
