🇺🇸 English Installation

Welcome

Welcome to my Kali Linux customization auto-install repository. This project installs and configures my custom BSPWM environment automatically.

1. Update your system

sudo apt update -y
sudo apt upgrade -y

2. Clone the repository

git clone https://github.com/ZLCube/KaliAutobspwm.git && cd KaliAutobspwm

3. Give execution permissions

chmod +x Autoinstall.sh

4. Run the installer

./Autoinstall.sh

5. Restart your session

kill -9 -1
